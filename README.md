# Xdebug — a Porta plugin

Debugs PHP with Xdebug: the vscode-php-debug adapter, found or installed for you.

![The xdebug page in Settings → Plugins](https://janalis.github.io/porta/screenshots/plugin-xdebug.svg)

This is `janalis/porta-xdebug`, one of the plugins bundled with
[Porta](https://github.com/janalis/porta), the terminal IDE for PHP. Porta
ships it already: turn it on under **Settings → Plugins**. Install this
package only to run a copy of your own, which shadows the bundled one.

- [Documentation](https://janalis.github.io/porta/plugins/xdebug/)
- [Writing a plugin](https://janalis.github.io/porta/plugins)

## Read-only

This repository is a read-only split of `plugins/xdebug` in
[janalis/porta](https://github.com/janalis/porta), updated on every push.
Report issues and send pull requests
